## Folder structure (branch `feat/v0.5-full-moodle`)

```
src/tools/
├── _common/              # shared helpers (visibility, upsert, idempotency shortcuts)
├── course/               # create / update / duplicate / archive / list / get_context
├── sections/             # create / update / reorder / hide / release / duplicate
├── content/              # publish_class_lesson, publish_resource, publish_activity_assign,
│                         # publish_forum, move_or_delete_resource, + existing preview/confirm
├── assessment/           # publish_exam_lesson, create_question_bank, import_gift,
│                         # edit_question_bank, configure_quiz, release_quiz, hide_quiz
├── students/             # list / enrol_csv / unenrol_student / create_group / assign_to_group /
│                         # change_role / reset_password
├── gradebook/            # get_grades / get_completion /
│                         # get_quiz_attempts / get_assign_submissions / grade_manually
├── communication/        # send_moodle_message / create_forum_announcement /
│                         # get_course_logs / get_site_info
├── calendar/             # create / list / update / delete
├── badges/               # list_user_badges / award_badge
└── primitive/            # ws_raw (escape hatch)
```

Each family owns its own subfolder with:
- `<tool>.ts` per facade.
- `_schemas.ts` per family for shared Zod schemas.
- Mirror folder in `tests/unit/<family>/` with `.test.ts` per facade + `_integration.test.ts`.

## Non-negotiable principles (repeated from design doc)

1. Idempotency by `idnumber` on every write (`mcp:<type>:<hash>`).
2. Zod validation before every WS call. No `any`.
3. Typed errors: `MOODLE_PLUGIN_MISSING`, `MOODLE_WS_TIMEOUT`, `MOODLE_INVALID_TOKEN`, `MOODLE_PERMISSION_DENIED`, `MOODLE_WS_EXCEPTION`.
4. Exponential backoff retry on 5xx and timeouts; no retry on 4xx.
5. Rate limit 10 req/s (configurable).
6. Each facade: unit test with `nock` + 1 E2E integration test against `bitnamilegacy/moodle:5.0.2` + plugin companion.
7. Default `hidden` mode for any new-content publication.
8. Domain-agnostic: the MCP never assumes Italicia/Alice. README and examples do mention Italicia as primary consumer.
9. Open-source MIT.
10. Node 20+ target, Node 24 LTS dev.

## Versioning rule for v0.5.x

- `v0.5.0`: first release with all 44 new facades (the 5 existing + `generate_video` already shipped).
